亚马逊棋（Amazons）人工智能博弈系统实验报告
一、项目概述
1.1 项目简介
本项目是一个完整的亚马逊棋人工智能博弈系统，基于C++语言开发，使用EasyX图形库构建可视化界面。系统实现了人机对战、双人对战、AI对战三种主要模式，并提供了完整的游戏功能。

1.2 游戏规则
亚马逊棋是8×8棋盘上的双人零和博弈游戏，每方有4个皇后（棋子）。玩家轮流执行两步操作：

移动己方皇后（皇后走法，可沿8个方向任意距离，不能穿过障碍）

放置箭矢（阻塞格子，永久不可通行）
游戏目标：使对方无法移动任何皇后

二、核心功能实现
2.1 基础功能
保存、读取游戏进度

棋子的合法移动和放置箭矢

游戏胜负判定

基本的图形界面交互

2.2 主要亮点功能
2.2.1 悔棋系统
双方均可悔棋若干步

集成在侧边栏按钮中，操作便捷

2.2.2 图形界面
精致的背景图片：主页面背景、棋子图片（黑色棋子、白色棋子、高光棋子、箭棋）

透明的PNG渲染：避免图片黑边的出现，实现圆形棋子的插入

鲜明的位置提示：用鲜艳的绿色和黄色分别标明棋子可以走的位置和箭可以走的位置

坐标系统：A-H、1-8行列标识

2.2.3 音频系统
背景音乐（bgm）：听着就很兴奋的音乐

多种音效：棋子选择时的音效、射箭的音效、倒计时的读秒音效（0-9秒）

音量控制滑条：可独立调节bgm和音效的音量

2.2.4 游戏设置
人机对战难度选择：简单和地狱两档难度

执棋方选择：可选择执黑还是执白

单步时限选择：在开局界面可以选择单步的时长

局内读秒条：随着单步时限逐渐减少，超时直接判负

2.2.5 游戏控制
暂停键：按下暂停键，一切暂停（包含读秒条）

多存档系统：支持多个存档槽位

操作引导：三步高亮提示（棋子选择→移动位置→放置箭）

三、算法设计与实现
3.1 AI算法设计
3.1.1 简单AI（MCTS基础版）
基于蒙特卡洛树搜索（MCTS）算法

四阶段循环：选择-扩展-模拟-回溯

UCB公式：UCB = 胜率 + C * sqrt(ln(父访问次数)/子访问次数)

评估函数：70%机动性 + 30%领地控制

3.1.2 地狱AI（用于Botzone对战）
神经网络增强：MCTS框架 + 神经网络评估

神经网络特性：5维特征向量、28个隐藏层节点

特征工程：机动性、领地控制、棋子分布等特征

开局库：通过Python爬虫抓取Botzone平台上的高质量对局

训练方法：遗传算法，每组40个子代，通过增加迪利克雷噪音和自对战优胜劣汰

struct MCTSNode {

3.3 算法优化
3.3.1 位运算优化
使用64位整数表示棋盘状态

通过位运算高效计算棋子的可达位置

快速判断棋盘格子的占用状态

3.3.2 性能优化
距离缓存：棋子可达位置BFS结果缓存

剪枝优化：根据游戏阶段保留高质量走法

内存池管理：预分配内存避免动态分配开销

从随机参数开始，每组40个子代

通过增加迪利克雷噪音和自对战进行优胜劣汰

随着训练时间增长，迭代轮数上万轮，神经网络逐渐收敛

多特征MCTS：结合多种局面特征进行搜索

AVX2指令集优化：使用SIMD指令加速计算
