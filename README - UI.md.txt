一、基础功能
保存、读取、移动等基本功能不在此处赘述，已经在线上会议中展示过了

二、亮点
1. 悔棋 - 双方可悔棋若干步

2. 精致的背景图片 - 主页面背景、棋子图片（黑色棋子、白色棋子、高光棋子、箭棋）

3. 透明的PNG渲染 - 避免图片黑边的出现，实现圆形图片（棋子）的插入

4. 让人听着就很兴奋的音乐 - bgm、棋子选择时的音效、射箭的音效、倒计时的读秒

5. 音量调节滑条 - 可调节bgm和音效的音量

6. 人机对战难度选择 - 可选择人机对战的难度（两档，简单和地狱）、执黑还是执白

7. 单步时限选择 - 在开局界面可以选择单步的时长

8. 局内读秒条 - 会随着单步时限而逐渐减少，如果超时直接判负，并且明确说出赢方是谁

9. 暂停键 - 按下暂停键，一切暂停（包含读秒条）

10. 鲜明的位置提示 - 用鲜艳的绿色和黄色分别标明棋子可以走的位置和箭可以走的位置，辅助下棋
